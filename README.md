## 실행 방법

```bash
# rustlings 실행 (대화형 워처)
rustlings

# 특정 연습 문제 실행
rustlings run <exercise_name>

# 다음에 풀 문제로 이동
rustlings hint <exercise_name>
```

## 디렉터리 구조

- `exercises/` — 풀어야 할 연습 문제들
- `solutions/` — 각 문제의 해답
- `Cargo.toml` — 프로젝트 설정
