# Rustlings

[Rustlings](https://github.com/rust-lang/rustlings) 연습 문제를 풀며 Rust를 학습하는 저장소입니다.

## 학습 진행 상황

- [x] Intro
- [x] Variables
- [x] Functions
- [x] If
- [x] Primitive Types
- [x] Vectors
- [x] Move Semantics
- [x] Structs
- [x] Enums
- [x] Strings
- [x] Modules
- [x] Hashmaps
- [x] Options
- [x] Error Handling
- [x] Generics
- [x] Traits
- [x] Lifetimes
- [x] Tests
- [x] Iterators
- [ ] Smart Pointers (진행 중)
- [ ] Threads
- [ ] Macros
- [ ] Clippy
- [ ] Conversions

> 위 목록은 커밋 히스토리를 기반으로 한 대략적인 진행 상황입니다.
> 정확한 상태는 `rustlings` CLI로 확인하세요.

## 실행 방법

```bash
# rustlings 실행 (대화형 워처)
rustlings

# 특정 연습 문제 실행
rustlings run <exercise_name>

# 다음에 풀 문제로 이동
rustlings hint <exercise_name>
```

## 디렉터리 구조

- `exercises/` — 풀어야 할 연습 문제들
- `solutions/` — 각 문제의 해답
- `Cargo.toml` — 프로젝트 설정
